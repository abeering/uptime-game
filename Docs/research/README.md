# Research and unresolved proposals

This folder keeps useful exploration that has not become current implementation or settled game design. A proposal is not placed here merely because it is unimplemented: broader shared Uptime intentions remain under [Design](../Design/Uptime_Design.md). Read these complete sources as hypotheses, and check current code and serialized scenes before treating a mechanical example as implemented.

- [clean.md](clean.md) — a short observation about cleaning an apparently empty node and invisible infections; no current mechanic is implied.
- [first-prototype-level.md](first-prototype-level.md) — an illustrative authored level shape and pressure arc. Its Packet-style ticks, event API, and concrete values are examples, while its run/level cohesion questions remain relevant to shared Uptime design.
- [topology-runtime-spec-v1.md](topology-runtime-spec-v1.md) — an unimplemented runtime pipeline proposal using Packet-side class names. The wider topology and network-growth goals remain in [shared design](../Design/Uptime_Design.md); this proposal is not a current contract for either scene.
- [connections-lane-spacing-continuity.md](connections-lane-spacing-continuity.md) — parked Connections presentation research on route-coherent lane spacing, occupancy-responsive gaps, and placing identity pills after geometry; no implementation work is authorized.
- [connections-geometry-capacity-v0.md](connections-geometry-capacity-v0.md) — measured Connections node/link/pill capacity, compact-footprint and local-junction comparisons, and static 16:9 references; no production geometry changes or full-topology feasibility claim.

- [connections-topology-stress-v0.md](connections-topology-stress-v0.md) — opt-in generated Connections trees with real traffic, 21 native 16:9 captures, diagnostics, and tier-by-tier presentation findings; no production topology progression or node-count limit is established.

- [playstyle-run-pacing.md](playstyle-run-pacing.md) — parked exploration of active/arcade versus ATC-inspired alt-tab run pacing, and the different attention rhythms each would demand; no mode or tuning is committed.
- [network-nouns-verbs-inventory.md](network-nouns-verbs-inventory.md) — compact infrastructure and operator-command vocabulary bank, with a chosen discussion order beginning with Load Balancer, Firewall, Replica, and Cache; no mechanics or implementation scope approved.

Research may be promoted through an explicit design decision. Keep its original alternatives and examples available when doing so.
