# Playstyle settings / run pacing — exploration

**Status:** Parked idea, not an approved design or implementation task. This is a possible Uptime-wide run option, not a rule for either prototype.

Could Uptime support different *attention rhythms* as a playstyle choice, rather than only varying difficulty?

- **Active / arcade:** The current gameplay direction: traffic and threats tuned to aggressive timing, frequent decisions, rapid commands, and near-continuous attention.
- **Alt-tab / background:** Inspired by playing ATC on easy with slow planes. Leave the game running, check in every minute or so, survey what's changed, adjust or prepare routes for new traffic, handle emerging problems, and go back to something else. The network still evolves, but meaningful intervention happens in occasional bursts rather than constant reaction.

Questions for later:

- Is this a playstyle setting, a distinct kind of run, or a separate axis from difficulty?
- Which pacing knobs would need to move together (traffic arrivals, hostile pressure, incident deadlines, time to respond) to make the slower style genuinely playable?
- How should the game summarize changes and preserve fair, consequential decisions when the player looks away?

**No decision yet:** This is a direction to explore after the core active gameplay loop is proven, not a request to slow current tuning or build settings UI now.
