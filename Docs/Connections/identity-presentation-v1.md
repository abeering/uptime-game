# Connections: connection identity presentation V1

This phase gives generated Connections traffic short randomized IDs and a restrained visual accent. It does not change Packet, the Connections allocator, route ordering, line packing, traffic profile selection, or simulation time.

`ConnectionTrafficDirector` shuffles all 260 lowercase letter-digit IDs (`a-z` followed by `0-9`), matching Packet's ID shape, with a seed-derived random stream separate from its traffic stream. It walks that pool once per run, skipping any ID reserved by an explicit queued plan or already used by the host. The host retains IDs in its case-insensitive run history after completion or blocking. Generated IDs therefore do not repeat within a run, while authored witness IDs and explicit longer IDs keep working. Exhaustion stops ambient generation with a warning; a manual high-demand request reports the exhausted pool. Pills and visible terminal IDs use uppercase, while command lookup remains case-insensitive and recorder data retains the canonical generated lowercase ID.

The six cyan, teal, and blue-green accents are serialized on the Connections scene's `LogicalPathPresenter`. Assignment starts when a connection becomes active, scans from a rotating cursor for a color unused by visible connections, and uses the cursor deterministically when all six are occupied. Its slot remains held through the visible departure and is released when the path view is destroyed. The at-speed beam uses the accent; slowed and stalled beams retain their orange and red warning treatments. Identity pill outlines continue to use the accent during warnings. Active Inspect cards use it for their identity and progress accents; completed history stays muted. The palette never enters LOAD, WORK, routing, or the run recorder.

Traffic, Geometry, Resource, and Recorder Witnesses cover deterministic IDs, explicit ID compatibility, pool exhaustion, six-color rotation and reuse, operation-transition stability, performance colors, and existing mechanics. At 16:9 in Play Mode, review 4–6 simultaneous connections, moving pills, arrivals and departures, slowed/stalled warnings, Inspect accents, and command focus. The six accents are intentionally close in tone; their separation needs human visual review.
