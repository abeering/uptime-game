# Reactive Identity Misdirection V0 Editor captures

The Reactive Identity Witness rendered both Connections gameplay scenes at 1280×720 and 1920×1080 using four concurrent paths on one route. Each scene and resolution has three frames:

- `stable`: the reactive connection advertises its initial false ID after 2.5 simulation seconds without an interaction.
- `reacted`: `kill` against that alias failed normally and immediately replaced the displayed ID while the other paths and pills remained in place.
- `revealed`: Probe on the occupied API–DB edge temporarily displayed the true ID while the false alias remained hidden for expiry.

The 12 PNGs were rendered by Unity 6000.3.11f1 in a batch Editor session. They show static layout and terminal text, not live animation or keyboard focus. Interactive Play Mode review remains necessary for the transition accent, crowded motion, command focus, and Probe expiry timing.
