# Payload Launcher V0 review

Scripted Play Mode frames are generated by `Tools > Connections > Capture Payload Launcher Play Mode Review` in each Connections scene. The batch entry point is `Uptime.Connections.EditorTools.PayloadLauncherCapture.Run`, with `-payloadLauncherScene Connections` or `ConnectionsAdvanced` and `-payloadLauncherCapturePath <folder>`. At 1920×1080 it records an active launcher connection, red Payload establishment at API, red traversal to DB, the armed DB interceptor, and the intercepted outcome. The sequence pauses automatic simulation and advances the existing simulation host explicitly.

The 8-second defense is armed during travel and catches the one-hop strike.

The combined batch logged `PayloadLauncherRegressionBatch PASS`. The launcher witness exercises both scenes, kills or cancels the carrier before completion, checks one typed launch and red establishment, catches targeted and two node-wide Payloads with one slot, observes missed DB infection and failed late interception, and compares coarse/fine seeded replay and recorder receipts. `ConditionWitness` covers existing Port Scan completion and kill behavior; `InfectionWitness` covers existing connection delivery. The Unity batch used a temporary runner in the isolated copy; the repository contains the focused launcher witness.

These scripted images establish rendered Play Mode states; they do not replace interactive review of keyboard focus, readability, or response timing.

To review interactively, open either Connections scene at 16:9 in Play Mode and use `spawn payload-launcher`. `inspect <connectionId>` should show its ordinary-looking purpose and progress. In one run, `kill <connectionId>` before the operation completes and verify no Payload appears. In another, let it complete; the API→DB Payload should appear red immediately. Use `intercept @ db` or `intercept <payloadId> @ db` promptly, and in a separate run allow impact to confirm the existing Phantom LOAD infection at DB. Check that API stays uninfected and that the terminal prompt retains focus after commands.
