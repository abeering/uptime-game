# Inspect status colors

Unity Editor previews of the authored Connections inspect UI at 1920×1080. The [full nominal scene](nominal-1920x1080.png) shows green active operation pills and `AT SPEED` lines beside blue-green titles, side accents, and progress fills. The [nominal close-up](nominal-operation.png) and [slowed close-up](slowed-operation.png) show the performance color change more clearly.

These renders use deterministic simulation states in an isolated Editor copy, not Play Mode. The three-stage `c3` arc used for the screenshots is temporary preview data; the authored scene is unchanged. Review the colors in Play Mode at 16:9 with `inspect c1`, `inspect c2`, and `inspect c3` while the connections run.
