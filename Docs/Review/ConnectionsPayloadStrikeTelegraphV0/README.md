# Payload Strike Telegraphing V0 review

These five 1920×1080 frames were generated by `PayloadStrikeCapture` in Unity 6000.3.11f1 Play Mode using `ConnectionsAdvanced.unity` and deterministic Payload spawns. The runner pauses automatic simulation and steps the normal host between frames. They document presentation states; interactive timing, motion, command focus, and legibility still need human Play Mode review.

| Frame | What to inspect |
|---|---|
| [01 intermediate orange](01-intermediate-orange-1920x1080.png) | `x1` crosses the EXT1 to WEB transit hop with orange line, socket, body, and ID. |
| [02 final establishing red](02-final-establishing-red-1920x1080.png) | The same `x1` starts its API to DB final hop; its newly growing line and socket are already red. |
| [03 final traversing red](03-final-traversing-red-1920x1080.png) | `x1` travels toward DB with red line, socket, body, and ID. |
| [04 one hop immediate red](04-one-hop-immediate-red-1920x1080.png) | A fresh API to DB Payload has a red line and socket during its first establishment. Its body appears when traversal starts. |
| [05 crowded orange and red](05-crowded-orange-red-1920x1080.png) | Staggered transit and final-hop Payloads coexist while ordinary link colors and node status remain readable. |

Run `Tools/Connections/Capture Payload Strike Play Mode Review` with `ConnectionsAdvanced.unity` in an interactive Editor to regenerate these frames. The command-line runner accepts `-payloadStrikeScene ConnectionsAdvanced` and `-payloadStrikeCapturePath <folder>`. The capture script runs from an isolated project copy without editing the scene.

The expanded `PayloadWitness` passed on both `Connections.unity` and `ConnectionsAdvanced.unity`. `GeometryWitness`, `InfectionWitness`, and `AmbientHostileActivityWitness` also passed in Unity batch Editor mode. Interactive review should compare both scenes at 16:9, follow an orange hop into immediate red establishment, inspect a one-hop Payload, observe lane reflow and crowded labels in motion, and test `intercept @ <nodeId>` and `intercept <payloadId> @ <nodeId>` while keeping the command prompt focused. Red announces a delivery attempt, not assured infection.
