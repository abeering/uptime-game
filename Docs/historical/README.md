# Historical sources and observations

This folder retains complete earlier contracts, phase plans and checkpoints, and old observations. They explain how Uptime reached its present state, but do not override current runtime, serialized Unity state, or the relevant [current-state page](../Uptime_Current_State.md). A design is not historical solely because it is unimplemented.

- [connections-v0.md](connections-v0.md) — original separate Connections experiment and phased hypotheses, established around [PR #1](https://github.com/abeering/uptime-game/pull/1). Later Arcade phases changed its mechanical baseline.
- [network-connection-grammar-v1.md](network-connection-grammar-v1.md) — useful physical-link/logical-connection and operation vocabulary alongside the superseded CPU, memory, disk I/O, and link-bandwidth allocator. [PR #3](https://github.com/abeering/uptime-game/pull/3) used the earlier model; [PR #4](https://github.com/abeering/uptime-game/pull/4) replaced allocation with target-node LOAD.
- [levels-phase1.md](levels-phase1.md) — Packet-era implementation checkpoint with shared attack/level design insights. Its phase instructions and "finalized" packet spawn sequence are not a current cross-prototype contract.
- [todo.md](todo.md) — older Packet-weighted task list, preserved without claiming its items are still open or approved.
- [bugs.md](bugs.md) — unverified Packet scanning observations; reproduce against the relevant current scene before treating them as current bugs.

For present Connections behavior see its [Current State](../Connections/Current_State.md) and linked integrated contracts. Substantive historical text remains intact; the V0 and grammar sources received archive notes, and the grammar's related-document path was retargeted after relocation.
